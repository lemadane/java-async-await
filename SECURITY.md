# Security Policy

## Supported Versions

Only the latest release version is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please do not report it in a public issue. Instead, report it privately by sending an email to the project maintainers.

We will acknowledge your report within 48 hours and work with you to coordinate a security release to resolve the issue.
